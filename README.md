# Background Color Changer 🎨

A simple browser-based tool that changes the page background to a new random color every second — built with vanilla HTML, CSS, and JavaScript.

**[Live Demo](https://siddhinaikare16.github.io/background-color-changer/)**

## How It Works

- Click **Start** — the background color changes to a new random hex color every second
- Click **Stop** — the color changing stops and stays on the last color shown

## Features

- Generates random hex colors on the fly (`#RRGGBB`)
- Uses `setInterval` to change the color continuously, and `clearInterval` to stop it cleanly
- Prevents multiple intervals from stacking if Start is clicked repeatedly
- Simple, centered UI with clear Start/Stop buttons

## Tech Stack

- HTML
- CSS
- JavaScript (no libraries or frameworks)
